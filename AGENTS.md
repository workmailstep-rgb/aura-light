# AURA project instructions

This is the standalone GitHub portfolio edition of AURA. Static HTML/CSS/JS in
`dist/` includes optional React Three Fiber islands built from `src/`. Preserve
the existing interface and interactions.

Before interface, identity or motion changes, read [DESIGN.md](DESIGN.md) and the
project-local [Awesome DESIGN.md skill](.agents/skills/awesome-design-md/SKILL.md).
The current user request and AURA's own design rules take priority over references.

Keep the cream/plum/lime identity, Russian «вы» address, English art captions,
sourced philosophical quotes and original lamp-halo logo. Distinguish the
neutral body finish from the pastel light color. AURA is a fictional concept.

Routine HTML/CSS changes need no dependency install. For 3D/Liquid Logo changes,
use `npm ci --ignore-scripts`, `npm run build` and `npm run test:3d`; commit source,
lockfile and generated `dist/assets/experience/` together. Run `npm run check`
after relevant runtime changes. Keep SVG fallbacks, motion/Save Data preferences,
offscreen pausing and the shared CSS settings bridge. Preserve font, dependency
and PolyForm Shield notices. Development references belong outside `dist/`.

The live demo is hosted separately. This repository does not contain hosting
credentials or deployment identity. Publishing to another host or setting up
GitHub Pages requires a separate user request.
